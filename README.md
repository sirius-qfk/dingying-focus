# EllesmereUI Gradient · 0.2.0-alpha

用户只调三档字号、图标尺寸和中心矩形范围，插件把数值应用到预先绑定的 EllesmereUI 元素。

**测试目标：WoW 12.1（接口 120100）/ EllesmereUI v9.3、v9.4。已完成源码核验和本地模拟测试，未经过游戏内验收。请先用备份配置测试，不用于正式副本。**

核心不变：用户只设置梯度数值；已接管的原生尺寸项必须显示档位入口，不保留第二套独立数值。v9.4 的梯度页使用官方 Plugin API；原尺寸控件替换和元素 Resize 仍属私有适配，**不属于 EUI 官方稳定接口，也未获官方支持**。这部分实机失败，就不能作为完整兼容版本发布。

## 安装与使用

1. 退出游戏，备份自己的 WTF 配置目录。确认 EUI 和对应动作条、冷却模块版本一致，使用 v9.3 或 v9.4 测试。
2. 解压安装包，把 `EllesmereUIGradient` 文件夹放入正式服 `Interface/AddOns/`。该文件夹内应直接包含同名 `.toc` 文件，不要多套一层目录。
3. 进入游戏，脱战后输入 `/eug`。v9.4 也可从 EUI 侧栏“梯度 → 梯度设置”进入；v9.3 保留原内嵌入口。
4. 修改三档数值；需要看清游戏区域时点击“布局预览”，拖动矩形边缘的方形手柄。点“返回设置”展开面板。
5. 点“应用”保存；“取消 / 返回”撤销本次未保存修改。“恢复原设置”退出接管，条件恢复接管前的值。

数字使用游戏 UI 坐标，不是显示器物理像素。字号范围 8–30，图标尺寸 16–96；矩形宽高至少 100 × 80，外层必须比内层大。超出屏幕、组间重叠或放不下时阻止本次应用，不偷偷改其他档位。

首次打开不会自动改动布局；修改任一数值开始预览，或直接“应用”使用初始值。预览标记仅在编辑时显示。进入战斗后停止布局修改；应用仍需脱战后手动确认，取消/恢复可延迟执行。

## 当前覆盖

| EUI 组件组 | 图标档 / 文字档 / 数量档 | 位置跟随 |
|---|---|---|
| 动作条 MainBar | 2 / 2 / 3 | 第三矩形下边界 |
| 动作条 Bar2、Bar3 | 3 / 3 / 3 | 第三矩形内的第二、第三行 |
| 冷却组 cooldowns | 1 / 1 / 3 | 第一矩形下边界 |
| 冷却组 utility | 2 / 2 / 3 | 第二矩形下边界 |

设置页会列出实际接入或跳过的原因。已接管的对应尺寸滑块显示档位入口，不再独立输入数值；恢复后还原原控件。图标裁剪形状仍由 EUI 保留，冷却组“尺寸”是其基础图标宽度。

## 重要边界

- v9.4 使用独立的正式插件设置分区，不覆盖 EUI 设置页、不绕过注册限制。v9.3 使用旧内嵌入口，两者分别适配。
- 已有锚定、宽高匹配、独立缩放、冷却组附加位移/分行尺寸/字号覆盖等情况会跳过。共享技能字号覆盖采用保守判定，可能使整个冷却组不接管。
- 不覆盖全部 EUI 数值、齿轮弹窗、全局同步或专精覆盖入口。外部冲突会暂停受影响模块，不抢写；不要同时用 EUI 解锁模式修改接管布局。暂停组仍占据的空间会参与避让；不能确认边界或出现关联布局冲突时，一并暂停本次修改。
- 配置按角色、EUI 配置名、专精、冷却布局名隔离；名称变化视为新配置，不自动迁移旧档位。
- 不改 EUI 源文件或替换原函数；会临时/持久修改已接管的 EUI 配置字段，并使用条件恢复记录。停用插件本身不等于恢复 EUI 数值。
- **更新 EUI、停用/卸载本插件、改配置名、导入/导出配置前，先在各已启用的配置/专精下执行“恢复原设置”。** 未知 EUI 版本停止接管，也不会冒险恢复旧字段。意外升级后可用升级前备份恢复；不要删除唯一备份。
- 用户档位与实际接管记录分开保存。0.1.0 的数据会先完整校验，再迁移到 schema 2；恢复记录标注实际来源版本。未知来源或契约的记录保留，不盲目重放。升级后不要直接降级到旧插件读取新配置；回退应恢复升级前备份。
- 没安装 EUI 时本插件仍能加载和保留配置，可用 `/eug status` 诊断，但不会凭空提供 EUI 元素。未知游戏接口版本也暂停接管；修改 TOC 版本号不代表验证通过。
- 只检查五个绑定组彼此的重叠，不避让其他插件窗口。默认数值是试用起点，不是已证明能降低疲劳的方案。

有问题时先输入 `/eug status` 查看接入状态，并记录 EUI/游戏版本、操作步骤、Lua 报错及截图。游戏内验收见 [验收清单](docs/IN_GAME_CHECKLIST.md)。

## 开发

运行时仅需要 Lua 与 WoW/EUI 接口，不需要 Node。Node 仅用于开发：

```sh
npm ci
npm run check
npm test
npm run package
```

绑定在 `Bindings.lua`，EUI 依赖全部集中在 `Integrations/EUI/`；源码契约相同的版本复用适配器，不按每个补丁复制一份。修改绑定前先恢复旧接管记录。安装包输出到 `dist/`，不包含 Node 依赖、测试或上游源码。

维护说明见 [开发地图](docs/ARCHITECTURE.md)、[兼容记录](docs/COMPATIBILITY.md)。版本依据：[v9.3](https://github.com/EllesmereGaming/EllesmereUI/releases/tag/v9.3)、[v9.4](https://github.com/EllesmereGaming/EllesmereUI/releases/tag/v9.4)、[官方 Plugin API](https://github.com/EllesmereGaming/EllesmereUI/blob/v9.4/PLUGINS_API.md)。本插件不附带 EUI。
