# EllesmereUI 梯度插件 · MVP

面向 WoW PvE 玩家的免费插件：**用户只调几组数值，插件自动调整对应的界面元素。**

测试目标：WoW 12.1 / EllesmereUI v9.3、v9.4（下称 EUI）。当前为 0.2.0-alpha，已通过本地模拟测试，待游戏内验收；独立于原 Tooltip 项目。

## 为什么做

> 从人的感知、注意与认知能力出发，结合 PvE 节奏，调配信息的位置、呈现强度与时机，让玩家少花精力寻找和辨认信息，更专注于游戏本身。

MVP 先实现视觉部分。矩形、字号和图标尺寸都是手段，不预设“越靠中心越大、越大越重要”；是否真正减少注意负担，需要实战验证。

## 用户怎么用

“梯度”就是一组尺寸档位。插件自带初始数值和元素绑定，用户不需要逐个找元素、分配档位。

| 用户调整什么 | 界面发生什么变化 |
|---|---|
| 各档字号 | 绑定到该档的文字一起变化 |
| 各档图标尺寸 | 绑定图标一起变化，排列与容器同步调整 |
| 各档矩形宽高 | 矩形保持屏幕中心对齐、由内向外嵌套；绑定组件组随指定边界移动 |

操作路径：**打开 EUI 中的梯度设置 → 改数值或拖动矩形边缘 → 预览 → 应用或取消。**

- 非战斗时实时预览，并临时标出受影响的元素；参考框只在编辑时显示。
- 已接管的 EUI 尺寸项显示所属档位，能跳转到统一设置页，不再独立输入数值。
- 这是核心验收条件，不以“保留原滑块 + 另设梯度页”替代。版本适配失效时明确暂停，不宣称完整兼容。
- 三类梯度分别设置，首版固定档位数量。用户无需处理绑定，也不需要额外内容才能使用。

## 插件怎么把设置变成结果

**梯度数值 → 绑定规则 → Resize（更新尺寸与布局）→ EUI 实际元素。**

例如，开发者可以规定：“某个冷却图标组使用图标第二档、文字第一档，位置跟随第一矩形的下边缘。”用户改这些档位，插件就更新对应部分，不影响其他元素。

开发时分开维护四部分：梯度数据、绑定规则、Resize、EUI 适配。绑定保存档位引用，不是复制数值；更换绑定元素不需要修改用户的梯度。EUI 的内部差异集中在适配部分。

矩形只移动预先绑定的组件组，不做全屏自动排版。数值不合法、矩形不能嵌套或布局放不下时，明确提示并阻止应用，不偷偷调整其他档位。

## 首版做多大

- **动作条**：图标、快捷键文字、数量文字，以及绑定组件组的位置与布局。
- **冷却管理器**：图标、冷却数字、层数文字，以及绑定组件组的位置与布局。

未适配的部分保留 EUI 原行为并明确标注。首版不做全部 EUI 覆盖、用户手工绑定、增删档位、战斗状态自动调节或声音功能，也不承诺其他版本已经兼容。

接入必须非侵入：不改 EUI 源文件、不覆盖原函数、不劫持配置表、不绕过安全限制。受保护修改延迟到脱战；不靠逐帧扫描或反复抢写尺寸维持效果。

## 怎样算完成

- 改一个档位，绑定元素正确联动，尺寸、排列和位置协调，未绑定元素不受影响。
- 预览可取消，应用可保存；重载、EUI 刷新和配置切换后仍正确，不串配置。
- 提供恢复接管前设置的操作，不无条件覆盖后续改动。
- 用户只操作一个梯度页面；实战中检查是否更容易找到信息，以及是否增加遮挡或干扰。

**交付边界：**v9.4 使用官方插件分区，v9.3 保留旧内嵌入口；原控件替换和 Resize 仍是版本限定的私有适配。固定三档、五个组件组；特殊锚定/覆盖设置会跳过，具体见 README。只有原控件替换、联动、安全和恢复都通过客户端验收，才算完成此 MVP。
